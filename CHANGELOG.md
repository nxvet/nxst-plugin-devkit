# Changelog

All notable changes to `@nxvet/nxst-plugin-devkit` are recorded here. The package follows
[semantic versioning](https://semver.org/); the profile interfaces (`SimulatorProfile`,
`CaptureProfile`) and the command-line flags are the public contract.

## Unreleased

Initial release: instrument simulator (`createSimulator` / `runSimulator`), live-capture server
(`createCapture` / `runCapture`), fixture and raw-capture readers, the SDK fixture writer,
the redaction engine, HL7 field rewriting and the REPL helpers.
